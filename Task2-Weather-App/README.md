Weather App 🌦️

OASIS INFOBYTE Internship – Task 2

A Python-based Weather Application that fetches real-time weather information for a given city using the OpenWeatherMap API.

Features

- Search weather details by city name.
- Displays current temperature in Celsius.
- Shows weather conditions and description.
- Displays humidity and wind speed.
- Fetches real-time weather data.
- Handles invalid city names and API errors.
- Simple and user-friendly interface.

Technologies Used

- Python
- Requests Library
- OpenWeatherMap API

Python Libraries

- "requests"

Installation and Setup

1. Clone the repository:
   
   git clone YOUR_GITHUB_REPOSITORY_URL

2. Navigate to the project folder:
   
   cd Python-Task2-WeatherApp

3. Install the required libraries:
   
   pip install -r requirements.txt

4. Run the application:
   
   python weather.py

API Configuration

1. Create an account on "OpenWeatherMap" (https://openweathermap.org/api).
2. Generate your API key.
3. Configure the API key in your Python application.

Note: Never upload your actual API key to GitHub. Use environment variables to protect it.

Sample Output

The application displays:

- City Name
- Temperature (°C)
- Weather Description
- Humidity (%)
- Wind Speed (m/s)
